# Tanishka Patil — Portfolio

A responsive personal portfolio website showcasing my projects, technical skills, experience, education, and achievements.

## 🚀 Live Portfolio

https://tanishka-portfolio-nl4v.onrender.com

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git & GitHub
- Render

## ✨ Features

- Responsive single-page portfolio
- Mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Active navigation while scrolling
- Resume download
- Project showcase
- Contact form
- MongoDB-powered contact form
- Deployed frontend and backend
